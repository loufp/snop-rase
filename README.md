# Snop Rase

Snop Rase — это проект-платформа для предсказаний и пари, вдохновлённая Polymarket, но с фокусом на **частные румы**.

## Идея проекта

Пользователи смогут создавать закрытые комнаты, приглашать друзей, делать ставки на события и заключать пари в формате дружеских споров.

## Ключевые возможности

- создание публичных и приватных рынков/споров;
- частные румы по приглашениям;
- ставки между друзьями;
- договорённости о пари внутри румов;
- прозрачная история ставок и результатов;
- базовая механика расчёта выигрышей.

## Фокус на MVP

Проект сложный для одного разработчика, поэтому текущая цель — двигаться к рабочему MVP:

1. регистрация и авторизация;
2. создание/вход в частные румы;
3. создание спора/рынка;
4. размещение ставок;
5. фиксация исхода и распределение выигрышей.

Мы стримимся хотя бы к MVP: сначала минимально рабочий продукт, затем расширение функционала.
